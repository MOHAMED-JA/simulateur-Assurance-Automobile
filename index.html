      Installer l'application

      Scannez le code : le simulateur s'ouvre sur le téléphone, prêt à être ajouté à l'écran d'accueil. Une fois installé, il s'ouvre comme une application et fonctionne sans connexion.

      Android ChromeVotre appareil

      1. Ouvrez le lien dans Chrome.
      2. Touchez Installer en haut de l'écran, ou le menu puis Installer l'application.
      3. Confirmez : l'icône apparaît sur l'écran d'accueil.

      iPhone SafariVotre appareil

      1. Ouvrez le lien dans Safari.
      2. Touchez Partager en bas de l'écran.
